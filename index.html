How dependencies work

Every phase waits on one other phase — or on the project start. The link type says which ends are tied together:

FS — finish to start. This phase begins the working day after the other one finishes. The normal “one after another” order.

SS — start to start. Both phases begin on the same day, so they run side by side.

FF — finish to finish. Both phases end on the same day — handy for work that must wrap up alongside something else.

SF — start to finish. This phase must be finished before the other one starts. Rare: useful for temporary work torn down when the next thing begins.

Lag / lead nudges the link by working days. +5 waits five extra days (lag). −5 pulls this phase five days earlier so the two overlap (lead). Leave it at 0 for no nudge.
